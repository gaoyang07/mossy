# mossy logo

`mossy-logo.png` is the project emblem, generated with the built-in image generation tool. The PNG has a transparent background; README typography supplies the project name separately so it follows GitHub's theme.

## Design

- Reachy Mini's two antennae and asymmetric camera eyes form the silhouette.
- An orange double-wave on the forehead takes inspiration from MOSS's intertwined brand mark and suggests simultaneous listening and speaking.
- Coral and warm ivory echo the official MOSS-Live model icon. Dark outlines keep the face readable at README size.

## Visual references

- [MOSS official site](https://www.moss.cn/) and its [brand mark](https://mosi-www-prod-new.oss-cn-shanghai.aliyuncs.com/website/brand/mosi-logo-cca510115a9b461b.webp).
- [MOSS-Live official product page](https://www.moss.cn/models/moss-live), describing full-duplex realtime interaction.
- [MOSS-Live model page](https://platform.moss.cn/docs/models/moss-live/) and its [orange model icon](https://studio-static.mosi.cn/platform/images/moss-model-icons/moss-live-1.0.png).

This is project-specific generated artwork inspired by those references.
